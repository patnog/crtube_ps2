# CRTube for PlayStation 2

Native PS2 homebrew port of CRTube. This project is intentionally isolated from
`apps/yo-player` while the PS2 platform backend and media pipeline are being
validated.

## Current status

- [x] Initial EE executable structure.
- [x] PS2SDK Makefile using the SDK's standard EE sample rules.
- [x] On-screen bootstrap/status output.
- [x] IOP/SIF initialization and network module loading.
- [x] Ethernet and DHCP integration based on the installed `tcpip-dhcp` sample.
- [ ] Validate Ethernet link and DHCP lease on physical hardware.
- [ ] DNS, TCP and HTTP tests.
- [ ] HTTPS/TLS backend.
- [ ] YouTube search and metadata extraction port.
- [ ] Thumbnail download, JPEG decode and GS rendering.
- [ ] Media demux, audio output and video decoder benchmarks.

No PS3-specific source files or libraries are linked by this target.

## Requirements

Install the PS2DEV environment and PS2SDK. The default expected locations are:

```sh
export PS2DEV=/usr/local/ps2dev
export PS2SDK=$PS2DEV/ps2sdk
export GSKIT=$PS2DEV/gsKit
export PATH="$PATH:$PS2DEV/bin:$PS2DEV/ee/bin:$PS2DEV/iop/bin:$PS2DEV/dvp/bin:$PS2SDK/bin"
```

## Build

From this directory:

```sh
make
```

The output is `crtube-ps2.elf`.

Clean generated files:

```sh
make clean
```

## Run on console

Start `ps2link` on the PS2, connect the console and development machine to the
same Ethernet network, then run:

```sh
make run
```

The `run` target uses `ps2client execee host:crtube-ps2.elf`.

## Directory layout

```text
crtube-ps2/
├── Makefile
├── README.md
├── bin/
├── docs/
├── iop/
│   └── irx/
├── include/
├── libs/
│   └── *_irx.c       # generated by bin2c from IOP modules
└── src/
    ├── main.c
    └── network/
```

Planned code is separated into platform, network, YouTube, UI and media modules
as those components are implemented. The network implementation embeds `ps2dev9.irx`, `netman.irx` and `smap.irx`
from the installed PS2SDK, and uses `-lnetman`, `-lps2ip`, `-ldebug` and
`-lpatches`. Its initialization and DHCP flow follow the installed
`samples/network/tcpip-dhcp` example. Hardware validation is still required.

## Scope and constraints

The target is a physical SCPH-700xx console with an Ethernet network adapter.
The application itself runs on the PS2; no companion server is part of the
target architecture.

Initial milestones are a bootable ELF, Ethernet/DHCP, DNS/TCP/HTTP, then the
YouTube search and thumbnail UI. Video decoding is a separate experimental
workstream. 480p30 is a performance target to measure, not a current guarantee;
480p60 remains a stretch goal.

## Initial memory-card configuration

The standalone build now reads the static network configuration from the first
valid file found in this order:

1. `mc0:/CRTUBE/IPCONFIG.DAT`
2. `mc1:/CRTUBE/IPCONFIG.DAT`

The file contains one line with three required values and an optional DNS server:

```text
<IP> <mask> <gateway> [DNS]
```

Example (DNS defaults to the gateway when omitted):

```text
192.168.15.99 255.255.255.0 192.168.15.1
```

Example with an explicit DNS server:

```text
192.168.15.99 255.255.255.0 192.168.15.1 1.1.1.1
```

`SMBCONFIG.DAT` is parsed independently, using `mc0:` first and `mc1:` second.
Its line format is:

```text
<IP>:<PORT> <SHARE_NAME>
```

Example:

```text
192.168.15.97:445 PS2SHARE
```

This is an initial configuration patch: SMB authentication, share mounting,
and SMB-backed logging are not enabled yet. Persistent logging is disabled in
this step so an ELF launched from a memory card cannot write logs to that card.
